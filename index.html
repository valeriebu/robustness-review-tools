Medical AI Robustness Review — Tool Suite

Systematic review tools for assessing the robustness of AI-based clinical decision support tools in mental health RCTs. Scoring framework across 10 dimensions (prediction models) or 6 dimensions (chatbots).

All tools run in-browser · No server required · Import your codebook Excel to score
Scoring Tools
📊
Prediction Model Scoring
Prediction models
Full robustness scoring for ML-based prediction and classification tools. Import your codebook Excel, score interactively, and export a radar chart.
10 dimensions · D1–D10 · Weighted questions · Gated D5/D6
💬
Chatbot Scoring
Chatbots
Robustness scoring adapted for conversational AI tools. D2 (data quality), D4 (internal validation), and D5 (retrospective validation) are excluded as non-applicable. D3 uses chatbot-specific questions.
6 dimensions · D1, D3, D6, D7, D8, D9, D10 · Chatbot D3 & D10 variants

How to use: Start with the Excel Row → Scoring Mapping to understand what your codebook fields map to. Then open the appropriate scoring tool, import your codebook Excel (one sheet per tool), and score. Use the Population Scope Match tool alongside D1 to assess how well the study population matches the intended use before setting the mismatch penalty. The Python script robustness_score.py automates batch scoring from the command line.
